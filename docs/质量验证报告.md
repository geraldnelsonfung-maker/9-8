## 5. 本次新增功能代码审查结论
### F15/F29 联网晨报 + 热点真数据（cloudfunctions/webSearch 新增）
- ✅ action=hotspot：5 源 RSS 并发抓取（allSettled，单源失败不整体失败）、来源强制标注、1h 缓存（hotspotCache 集合）、全源失败降级旧缓存
- ✅ action=briefing：订阅校验（subscribed+expiredAt）→ 天气（和风，缺 KEY 降级 null）→ 偏好排序 → LLM 摘要（JSON 输出校验）→ **只有 LLM 调用才消耗日限额**（10 次/日，usage 集合 intelDate/intelUsed）
- ✅ getBriefing 懒加载策略：定时器不逐用户调 LLM（避免 cron 超时），用户首开晨报时补充 intel 并落库；每步 try/catch 不阻塞晨报
- ✅ 前端：weapp 端 getHotspot 走 webSearch，失败降级本地 mock；H5 保持 mock
### F05 按住说话 ASR（VoiceButton 重构）
- ✅ 插件路径：Taro.requirePlugin('WechatSI')，onRecognize/onStop/onError 全接；转写文本进 askAssistant 对话链路
- ✅ 降级链：插件未配置 → RecorderManager 纯录音 → 上层提示「插件未配置」；H5 mock 转写不变
- ✅ 修复潜伏 bug：onResult 用 ref 转发（原实现事件注册捕获首帧闭包，额度状态读取会过期）；卸载时停止录音防泄漏；滑动取消丢弃结果
### 晨报「今日情报」UI
- ✅ intel 区块：天气 chip + 情报条目（每条带来源）+ 降级/AI 标注说明；双语 key 齐全（zh/en）
