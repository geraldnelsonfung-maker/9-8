# Release Notes · 私人晨报助理 v1.0 体验版基线

> 2026-09-10 · 对应 PRD v2.0 · 递交范围：M7 v2.0 信息架构 + 本次补齐的 F15/F29/F05

## 这是什么
把散落在微信里的日程、待办和信息整理成一份可对话的私人晨报：转发消息给小程序，AI 自动提取并智能排班；每天早上收到晨报推送，用文字或按住说话与助理交互；日历页管好一天，热点页聚合偏好资讯。

## 新增（本次递交）
- 🌐 **今日情报**（订阅专属）：晨报内新增天气 + 偏好资讯情报区，每条标注来源，AI 提炼 3-5 条短句；失败自动降级不阻塞晨报；每日 10 次生成额度
- 🔥 **热点页真数据**：资讯流接入 RSS 聚合云函数（36氪/少数派/爱范儿/虎嗅/澎湃），每条强制标注来源，1 小时缓存，免费可用；抓取失败自动降级
- 🎙 **按住说话上线**：微信端接入「微信同声传译」插件，说完直接出转写进对话；插件未配置时自动降级并提示，不阻断
- 🤖 **AI 悬浮球可拖动**：全页面常驻的 AI 助手悬浮球支持拖到任意位置（自动避让边界与 TabBar），拖动不误触面板
- 🐛 修复：语音按钮事件闭包过期（额度校验读取旧状态）、热点资讯分类标签缺失

## 已有核心功能（v2.0 基线）
- 5 Tab：晨报 / 收件箱 / 热点 / 日历 / 我的
- 收件箱：粘贴文字或截图 → AI 提取日程待办 → 冲突检测 → 逐条确认入库
- 晨报：今日日程 + 待办勾选 + 昨日收藏摘要；「🧠 深思」模式；工作助手（总结/要点/建议）
- 日历：月视图打点 + 单向写入手机系统日历
- 购物清单（兜底形态）：添加/勾购/手动比价记录 + AI 联网比价（标注来源与参考性）
- 全局搜索、浏览历史、主题换色、中英双语、头像更换、客服入口
- 合规：协议/隐私入口、注销（≤3步+二次确认）、AI 生成内容标注、授权管理

## 已知限制
- 手机号登录、微信支付：待企业主体资质与商户号（体验版为演示流程）
- 购物比价/代下单完整形态：待电商类目资质与平台 API（界面已标注"升级中"）
- 语音转写需在小程序后台添加同声传译插件后才生效
- 资讯/天气依赖外部 RSS 源与和风天气服务，异常时自动降级为缓存或基础内容
